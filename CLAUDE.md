# «Гонка за искусственным интеллектом» — инструкции для облачной сессии

*Прежнее рабочее название — «Счёт за интеллект»; «счёт» остаётся главным приёмом страницы.*

Аналитический эксплейнер на русском: во что обходится гонка за искусственным интеллектом — кто платит, что мир получает взамен и чем рискует. Открывается кинематографичным экраном-«штабом», дальше — редакционная вёрстка на «бумаге». Итог — один самодостаточный HTML-файл, который открывается в любом браузере без сети и публикуется на GitHub Pages.

Полный замысел, структура блоков и визуальная концепция — `docs/content-plan.md` (раздел 3 «Каркас страницы» и «Визуальная концепция»). Прочитай его перед первой задачей.

## Кто что делает

- **Эта сессия — код:** каркас страницы, вёрстка блоков, графики, интерактивы, мобильная версия, тёмная тема, сборка, проверки, публикация.
- **Исследовательский чат (Cowork) — контент:** рисёрч, фактчек, текст, редактура. Результат — контент-пакеты `content/NN-*.md` (формат — `content/README.md`) и реестр утверждений `data/claims.csv`.
- **Один источник правды.** Текст, цифры, заголовки графиков и подписи берутся из пакетов как есть. Не переписывай их и не «улучшай». Нашёл ошибку, противоречие или график не строится по описанию — запиши вопрос в `docs/questions.md` (блок, место, что не так) и продолжай с тем, что есть.
- Верстай только пакеты со статусом `готов к вёрстке`. Для остальных блоков оставь аккуратную заглушку.
- `data/claims.csv`, `docs/*.md` (кроме `docs/questions.md`) и `content/**` не редактируй.
- Исключение: правки владельца из режима правки (файл `pravki-….md` из `edit.html`) применяй к `content/**` скриптом `scripts/apply_edits.py` — отдельным коммитом «Правки владельца из режима правки», без изменений сверх файла правок. Пропущенные скриптом правки не додумывай: перечисли их владельцу.

## Технические требования

- **Один файл, без сети в рантайме.** Шрифты — подмножества woff2 в base64 (кириллица + латиница, см. `prototype/build_proto.py`); D3 v7, topojson-client и карты — встроены из `data/lib/`. В облачной среде CDN закрыты, и это совпадает с требованием: всё нужное уже лежит в репозитории.
- **Сборка — скриптом** (Python или Node): пакеты `content/*.md` + шаблон → HTML. Повторяемо одной командой, команду опиши в README.
- **Стек:** ванильный JS + D3 + SVG. Без фреймворков, если нет веской причины.
- **Размер** — ориентир до 2–3 МБ; следи за шрифтами и картами.
- Прототип — не догма по коду, но эталон по виду: переход через сетку единиц, «счёт» на полях, карточки графиков, теги, подсказки, тёмная тема.

## Визуальная система (из прототипа)

- **Цвета — токены на `:root`**, тёмная тема по системной настройке и переключателю (`auto / светлая / тёмная`), выбор хранится в `localStorage` внутри `try/catch`.
  - светлая: бумага `#F0EFEB`, тушь `#1C1C1A`, серые `--ink-2 #4A4944`, `--ink-3 #5E5D57`, `--ink-4 #6A6963`, линии `#C6C5BF` / `#DEDDD6`; дебет `#b8432f`, кредит `#2e5c9e`;
  - тёмная: бумага `#1C1C1A`, тушь `#F0EFEB`; дебет `#d9654f`, кредит `#5c8bd6`;
  - компании в теле страницы различаются оттенком серого и формой значка (OpenAI — круг, Anthropic — квадрат, Google — ромб), цвета компаний живут только на экране-штабе.
- **Шрифты:** Source Serif 4 (текст), IBM Plex Sans (графики, подписи, интерфейс), IBM Plex Mono (счёт, штаб). Лицензия SIL OFL.
- **Сетка:** поле 210 px · колонка текста до 680 px · зазор · поле счёта 250 px. Широкие фигуры выходят на левое поле. Меньше 1180 px счёт уходит в плашку внизу экрана, меньше 720 px — одна колонка с полями 16 px.
- **Грамматика графиков** — по образцу Lieflat Charts (лицензия PolyForm Noncommercial: приёмы берём, **код не копируем**):
  - карточка: заголовок-вывод (законченная мысль, без точки) → подзаголовок с легендой через «·» → график → строка источника прописными с разрядкой;
  - волосяные линии, линии бухгалтерской книги на фоне, много воздуха, сплошные заливки без теней и градиентов (свечение — только в штабе);
  - один смысловой акцент на график: красный — кто платит, синий — что получаем;
  - площади — через корень из значения, оси столбцов не обрываются, двух осей Y нет;
  - подписи прямо у линий и точек, легенда — только когда без неё нельзя;
  - у каждого блока своя форма графика, шаблоны не повторяются.
- **Взаимодействие:** подсказки дополняют, но не прячут главное (всё важное видно без наведения); зоны нажатия не меньше 24 px; подсказки работают с клавиатуры (фокус); анимация — быстрое появление при прокрутке, при `prefers-reduced-motion` — статичный вид.
- **Счёт на полях:** строки печатаются, когда виден абзац с якорем; позиции прошлых блоков сворачиваются в одну строку и раскрываются щелчком; счёт всегда помещается в экран; внизу — «ИТОГО ··· —» и «у строк разные единицы».

## Язык и типографика интерфейса

Текст приходит из пакетов готовым. Для подписей, которые ты пишешь сам (кнопки, подсказки интерфейса, `aria-label`):

- кавычки «ёлочки», внутри — „лапки“; буква ё везде; длинное тире с пробелами, короткое — в диапазонах без пробелов (2024–2026);
- неразрывный пробел между числом и единицей (17,3 ГВт, 21 месяц), узкий неразрывный — между разрядами (7 662); запятая в дробях; «млн», «млрд», «трлн» без точки;
- числа форматируй через `Intl.NumberFormat('ru-RU')`;
- без канцелярита и англицизмов там, где есть русское слово; склонения по числу (1 строка, 2 строки, 5 строк).

## Проверка перед каждым PR

1. Сборка проходит одной командой.
2. Скриншоты Playwright: 1440×900 светлая, 1440×900 тёмная, 1024×768, 390×844; кадры — холодный старт, середина перехода, финал перехода, каждый свёрстанный блок и график.
3. Нет ошибок в консоли, нет горизонтальной прокрутки ни на одном размере.
4. Подписи графиков не наезжают на точки и друг на друга; счёт помещается в экран.
5. В описании PR — что проверено и что осталось.

Playwright ставится через pip или npm. Если браузер не скачивается (сеть среды ограничена), скажи об этом: владелец переключит доступ к сети в настройках окружения.
