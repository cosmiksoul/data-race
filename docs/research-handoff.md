## Порядок работы над блоком

Для каждого блока — одна задача. Порядок шагов:

1. **Рисёрч и фактчек.** Взять описание блока из плана и строки реестра `data/claims.csv` с его номером. Недостающее — найти и проверить по `docs/fact-check/instructions.md`. Новые строки — в отдельный файл `data/claims-NN.csv` того же формата (не в общий `data/claims.csv`: параллельные сессии иначе конфликтуют при слиянии); в общий реестр их переносит финальное ревью.
2. **Черновик текста** по правилам раздела 7 плана: теги ФАКТ / ОЦЕНКА / ПРОГНОЗ, контраргумент рядом с «страшным» числом, термины — в подсказки.
3. **Редактура** — отдельный агент с чистым контекстом: видит только текст и правила, возвращает список «было → стало → почему» (образец — `docs/review-06.md`). Если на claude.ai включён навык `russian-editorial-style`, облачные сессии подхватывают его автоматически.
4. **Корректура** — типографика: «ёлочки», ё, тире, неразрывные пробелы (число + единица, число + «раз», даты).
5. **Контент-пакет** `content/NN-slug.md` по формату `content/README.md` + данные графиков `content/data/NN-*.csv`. Статус `готов к вёрстке` — только после шагов 3–4 и финального ревью в исследовательском чате. Черновики фабрики получают статус `черновик`.

## Готовая формулировка задачи

Для облачной сессии или нового чата с доступом к репозиторию:

```
Прочитай docs/research-handoff.md, docs/content-plan.md (разделы 1–4, 7 и блок NN)
и docs/fact-check/instructions.md. Задача — контент-пакет блока NN.
1) Собери и проверь цифры: строки реестра NN-* плюс недостающее. Новые строки —
   в data/claims-NN.csv по инструкции фактчекера; общий data/claims.csv не меняй.
2) Напиши текст блока по правилам раздела 7 плана.
3) Проведи редактуру отдельным агентом с чистым контекстом (только текст и правила),
   правки сохрани в docs/review-NN.md, затем корректуру.
4) Собери content/NN-slug.md по формату content/README.md (status: черновик)
   и данные графиков в content/data/. Код и вёрстку не трогай. Открой PR.
5) В описании PR перечисли: что не удалось проверить, где цифры расходятся
   с реестром, какие вопросы остались.
```

**Про сеть в облачной сессии.** Окружение по умолчанию («Trusted») пускает только к реестрам пакетов и GitHub. Для рисёрча, скорее всего, понадобится переключить окружение на полный доступ к сети в настройках claude.ai/code, иначе сайты с первоисточниками не откроются.

## Правила, которые легко забыть

- В запросах к API и сайтам (SEC и др.) не указывать личную почту автора — ни в заголовке User-Agent, ни в параметрах. Если сервис требует контакт, использовать нейтральный: `data-race-research (research@example.org)`. Это же прописывать в задании каждому субагенту.
- Не ссылаться на СМИ из белорусского перечня экстремистских материалов (для анализа читать можно, в реестр и текст не попадают).
- Главу Республики Беларусь, если он упоминается, называть официально: «Президент Республики Беларусь А. Г. Лукашенко», далее «Президент».
- Глава 14 касается и Anthropic (случай ART, сентябрь 2026), а рисёрч и текст готовит Claude — модель Anthropic. Указать это в методике, как в блоке 13, и проверять такие случаи по первоисточникам обеих сторон.
- Самоотчёты компаний и утечки помечать явно; «не подтверждено» в текст не попадает.
- Метафору проверять буквальным прочтением; без оценочных образов, которые читаются как обвинение.
- Заголовок графика — законченная мысль без точки; у каждого блока своя форма графика.
